# 产品上下文：REQ-010 直播会话的工作目录与 Skill 设置

## 已确认的需求

**Requirement ID** `REQ-010` · `livestream-capabilities` · P1  
**来源** 当前用户要求先交付直播控制台的工作目录与 Skill 设置，并沿用下次新直播会话生效的约定。本文是待主 Agent 验收的产品规格，生命周期以 `state.json` 为准。

### 权威规则

CFG-01～05 定义配置行为，SCN-01～07 定义验收例子。工程和课程上下文引用这些条目。历史记录与源码观察分别用于追溯和 Plan 核实。

### 需求

**NEED-001（confirmed）** 主人在现有直播控制台保存工作目录、显式 Skill 来源和指定资料范围，在控制台发起下一次新直播会话后核对实际生效的配置、Skill 加载和资料读取。此前明确选择“下次新会话生效”和“加载技能＋读取指定资料”。原始需求及历史决定见 [REQ-008](REQ-008.product.md#已替代条目)。

### 约束

- **CON-001（confirmed）** 仅 owner 管理配置。新增能力限于显式 Skill Markdown 加载及指定资料的有限只读访问。沿用已确认的 REQ-008 首版权限。
- **CON-002（confirmed）** 复用现有控制台、直播 Agent、模式与设置，当前交付范围为从该控制台发起的新直播会话。来源为当前用户请求及 REQ-002 已有平台边界。

### 决定

- **DEC-001（confirmed）** 已确认的生效时机与读取范围沿用 NEED-001。清除目录、关闭配置或移除来源也只改变之后创建的会话，见 CFG-02。
- **DEC-002（confirmed）** 配置可在本地直播会话独立验收，先于课程互动与真实播出交付。拆分方式由主 Agent 根据当前请求确定，课程消费本条能力。[REQ-008](REQ-008.product.md)保留课程规则及原归并记录，[REQ-009](REQ-009.product.md)保留历史取消记录。
- **DEC-003（confirmed）** 在现有控制台设置抽屉增加同类设置，复用保存和状态反馈交互。该局部布局由主 Agent 在既有入口范围内确定。

### 范围外

课程播放器、弹幕课程控制、课件制作与发布、推流和观众端改动均由各自需求处理。新增能力限于 CON-001，不增加 Shell、写入、插件安装、通用文件访问、私信或账号操作权限。

### 开放问题

已确认范围和验收条件没有待用户选择的项。接口、资源读取预算、目录校验、Skill 原生复用与实际会话接线留给 Plan 核实。

#### 边界情况与体验

- 复用 [现有直播设置抽屉](../../packages/dsh-livestream/src/console/console.tsx#L875) 的表单及错误反馈。明确显示未保存、保存失败、已保存待新会话生效、当前实际快照或无活动会话。关键状态可用文字读取，输入保留标签、键盘操作和窄屏布局。
- 控制台以外的观众、公开舞台和直播输出不得收到本机路径、凭据或堆栈信息。状态或来源的细节对 owner 展示。
- SCN-01～07 可映射到既有抽屉和新会话旅程，无新增导航或待确认视觉方向。本轮复用既有设计，不制作独立原型。静态规格没有提供渲染、无障碍或交互运行证据。

### 需求 *(必填)*

#### 功能需求

- **CFG-01 owner 与可核对状态**。仅 owner 可读取管理配置与修改工作目录、Skill 来源及资料范围。控制台分别反馈已保存设置、当前活动快照以及 Skill 实际发现、可用和加载状态。Skill、课件及观众内容无法更改配置或权限。来源 NEED-001、CON-001。
- **CFG-02 保存、会话快照与恢复**。工作目录可留空并沿用原有默认。一次保存经过校验并整体成功后才替换上次保存结果。无效或不可读的目录、无效 Skill 声明、不同来源的同名冲突和写入失败均保留原配置并给出可修正反馈。同一规范来源重复提交只产生一份加载。控制台创建新直播会话时取得一份已成功保存的配置，整个会话固定采用该快照及其中加载的 Skill 定义。保存与创建重叠时，新会话只会取得一个完整的已保存版本。修改、清除、删除或关闭设置不会更改活动会话或在途工作，也不会自动创建会话、切换或开播。宿主重启恢复最近成功保存的设置并重新检查路径有效性，失效来源标记不可用，失效 cwd 需要修正或清空后再用该配置开始新会话，避免回退到未选择的位置。来源 NEED-001、DEC-001。
- **CFG-03 实际加载与能力边界**。只从 owner 显式指定且启用的来源加载 Skill Markdown 并让会话实际可用。未找到、校验失败和已加载但缺工具能区分。加载不会引入 Skill 所需的脚本、依赖或权限，也不扫描 home、工作目录下的默认目录或全局 Skill 集合。来源 CON-001、DEC-001。
- **CFG-04 指定资料的有限只读访问**。仅允许读取 owner 指定资料根内的内容，访问时按实际目标校验边界，拒绝绝对路径或相对路径越界及符号链接逃逸。cwd 用于会话工作上下文，独立于读取授权。读取量受限，预算由 Plan 明确。快照固定允许的资料范围，文件失效时反馈不可用。来源 CON-001、DEC-001。
- **CFG-05 兼容和删除语义**。未新增设置时保留原行为。新增设置保存与原房间、模式、声音、模型和查询配置兼容。移除来源或资料授权只变更后续会话的配置，磁盘 Skill 和资料文件保持原样。来源 CON-002、DEC-001。

#### 关键实体

| 实体 | 含义 |
|---|---|
| 已保存配置 | owner 最近一次整体保存成功的值，包括可选 cwd、显式 Skill 来源及指定资料根。 |
| 活动会话快照 | 控制台创建该直播会话时采用的配置及 Skill 加载结果。 |
| Skill 来源／资料根 | 分别授权发现及加载 Skill Markdown、读取指定范围内的资料。 |

## 发布后观察计划（SDLC 补充）

- **观察条目** 主人能否区分当前会话和待生效配置，并在新会话用到所选 Skill 和资料。
- **基线和判断方式** 当前没有集成基线。按 SC-001/002 核对首次配置保存、首次新会话和一次失败恢复。
- **观察窗口和负责人** 首次启用设置时，由 owner 核对控制台状态，交付方记录实际加载、范围内读取和拒绝结果。
- **反馈回流** 配置、生效或访问边界缺陷回到本需求。课程体验沿 REQ-008 跟踪。来源 NEED-001、DEC-001。
