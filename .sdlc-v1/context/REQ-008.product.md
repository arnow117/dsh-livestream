### 需求

#### NEED-001：复用既有课程，观众通过弹幕参与（confirmed）

- **陈述**：主人在现有直播控制台和舞台开始、讲解并控制已有 Papermorph 杠杆课件；观众可针对当前课程提问、作答和请求当前实验允许的参数。无需持续盯住新增课程窗口。
- **用户证据**：“想把这个对话里面的做课程能力放进来，并在直播间提供交互，可以做么”；用户选择“已有课件＋弹幕互动（推荐）”。[课程来源 chat](codex://threads/01a1c0ab-c09d-7b81-9cd2-628ccf0efcdd)已由主 Agent 用 `read_thread` 核对。
- **预期结果**：观众看到当前课程状态和已应用互动，听到相符讲解；主人在原控制台能核对实际处理结果。

#### NEED-002：为直播会话配置技能和指定资料（confirmed）

- **陈述**：主人能够增加后续允许的技能来源和工作/资料目录；首版加载技能 Markdown、读取明确指定的资料，新增技能或更换主目录从下次新会话生效。
- **用户证据**：“后续如果我想在这个会话里再加更多skill和工作目录（就比如上面聊到的那个课件）该怎么做？这次修改也看看把这个做了吧”；随后选择“下次新会话生效”和“加载技能＋读取指定资料”。
- **预期结果**：保存配置、活动快照、实际发现/加载、资料读取和缺工具状态可区分，今后增加同类只读技能无需逐个重写 prompt。

#### 功能需求：课程与互动（唯一规则定义）

- **CRS-01 主人控制与状态**：仅 owner 开始、暂停、继续、选择现有章节/步骤、重置和结束。当前唯一课程是下表单章资产，不构造不存在的章节。开始前确认资料与展示能力有效；加载/播放失败或未知明确反馈，不报告成功。暂停冻结课程进度、旁白和观众状态变化，保留当前画面/参数；继续从仍有效状态运行，不跳过题目。题目完成或实验后继续由主人控制；重置回本课初始状态并保持暂停，等主人开始/继续（实验默认见资产表），清本轮题目与实验结果。新会话或宿主重启不自动恢复进度、开课或开播；主人可重新选择既有步骤。来源：NEED-001、CON-003、主 Agent 有界控制决定及既有课件手动继续行为；例：SCN-08、16、19。
- **CRS-02 内容与获准输入**：内容、题目判定、实验参数和计算均以资产表所列现有课件为准，不重造教学模型。观众只可回答当前开放题、提出课程问题、请求当前实验的一项明确获准参数；不接受下一步、重置、结束、改固定阻力或任意命令。输入必须语义明确、单位正确、数值有限且符合范围/步长，不能截断、四舍五入或猜测；不适用当前状态则拒绝并给出下一步。来源：DEC-001、CON-002/003、已选课件事实；例：SCN-09、11、12。
- **CRS-03 串行选择与可核对反馈**：沿既有弹幕选择/串行响应能力，每次只执行一项有效动作；反馈能关联实际选中输入、当前步骤、实际完成/拒绝/过期结果，不在真实应用前宣称成功。多条有效实验请求依次以当前状态验证后应用；不承诺所有消息都被选中，也不承诺网络到达的绝对 FIFO，不引投票/排行榜或新冷却玩法。有界排队、等待和去重预算由 Plan 选择并验证，不无限执行。来源：CON-003；例：SCN-11～13。
- **CRS-04 当前题与重复输入**：选中的答案只影响其对应的当前课程轮次/题目尝试。沿原课件：错误显示解析并保留作答，正确完成当前题并锁住结果；后续同题答案不能改写已完成结果或推进下一题。语义相同但来自不同观众的消息不是同一个传输事件；重复事件不重复应用。当前题关闭、重开、重置或切步后，旧尝试失效，不能只因题目名称相同继续使用旧答案。来源：既有 quiz 行为、CON-003 及主 Agent 旧题隔离决定；例：SCN-09、10、13、16。
- **CRS-05 当前状态与主人优先**：owner 操作具有最终控制权。动作和回答绑定有效直播目标、会话、课程轮次、步骤/题目尝试及其所依赖状态；实际应用、生成口播和输出前均不得让失效结果污染当前状态。主人暂停/切步/重置/结束生效后，先前未完成动作不得反向覆盖，旧数值回答不能配新画面；已播内容无需追溯撤回。不能可靠确认状态时不声称已执行，提供当前事实或说明过期。来源：CON-003、主 Agent 状态隔离与主人优先边界；例：SCN-10、13～17。
- **CRS-06 讲解与音频协作**：保留既有课件预录旁白；现有串行调度选中课程问答时，先暂停课程进度/旁白，再由现有GLM依据有效课程状态作答并经yovoice输出，声音不能重叠。实际回答播放完成后，仅当暂停前课程原在播放、同一课程轮次/步骤仍有效，且owner没有另行暂停、重置、切换或结束时，从暂停位置自动继续；本来已暂停/等待作答的课程不因此跳步。回答失败、播放状态未知或归属失效时不自动续播，保留清晰反馈等主人处理；不能把模型/合成完成当已播完。口播、字幕、步骤和已应用参数的事实一致；课件读取、工具返回、模型完成、合成和实际播放分别报告。旧数值答案按CRS-05拒绝，不更换模型/TTS、重录或重新生成全课音频。来源：DEC-004、NEED-001、CON-001与主Agent状态一致边界；例：SCN-14、15。
- **CRS-07 生命周期与断线**：结束课程/下播、目标或会话实际切换使旧课程动作、回答和待播内容失效，晚到结果不得新输出或自动恢复直播。结束课程本身不等于下播，保留仍有效的直播/主人普通交互，不取消无关查询、不停共享服务。仅断抖音订阅停止新平台输入并清除该订阅尚未完成的观众课程动作/回复，不等于结束仍有效本地课程或停共享采集；主人本地控制保持可用，重连须显式并只处理新有效输入。舞台断开不能报告实际播放；同一有效会话重连对齐当前状态，不补播旧问答，重启按 CRS-01/CFG-02处理。来源：REQ-002/006 既有断订阅语义及主 Agent 课程旧结果边界；例：SCN-17～19。
