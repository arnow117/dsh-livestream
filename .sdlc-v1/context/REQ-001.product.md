### 需求

#### NEED-001：在直播控制台调整音色并立即应用

- **状态**：confirmed。
- **陈述**：主播在现有直播控制台修改音色描述，保存后后续声音直接使用新配置，不必重启服务。
- **用户证据**：“把音色设置加到直播控制台里吧，支持修改音色描述和试听，保存后直接生效，不用重启。”
- **问题**：目前本地音色参数依赖启动环境；控制台没有完整的编辑、试听与生效反馈路径。
- **确认来源**：本次用户请求，2026-11-09；不是新一轮确认。

#### NEED-002：保存前试听

- **状态**：confirmed。
- **陈述**：主播能够试听所编辑音色，判断是否适用再决定保存。
- **用户证据**：同 NEED-001 的“修改音色描述和试听”。
- **目标用户**：已登录 Harness、具有直播控制台操作权限的主人。

#### NEED-003：整合现有云端和本地语音

- **状态**：confirmed。
- **陈述**：整合直播插件现有豆包语音设置与已接入的本地语音。
- **用户证据**：“这个项目里我看原生也有些tts模型配置在后台，你看看怎么整合优化下，可以云端也可以本地这样子”。用户随后明确“原生”指直播插件设置页的豆包配置。
- **确认来源**：用户请求与后续澄清，2026-11-09。

### 用户场景与测试（必填）

#### 用户故事 1：修改正在使用的声音（优先级：P1）

主人在“直播 → 设置 → 声音”调整配置并保存，以后续一句声音判断是否生效。价值是无需重启即可调音；独立测试为编辑、保存、触发新一句并刷新控制台。

1. **AC-01**：给定 yovoice 当前描述为 A，且直播正在使用的一句声音已经开始合成或播放，当主人将描述改为 B 并保存成功，则下一次新发起的合成使用 B；该句继续使用 A，不因保存中断。尚未被直播使用的预备音频可失效，不影响这句声音。
2. **AC-02**：给定声音设置已保存，当刷新控制台或正常重启插件，则已保存选择仍在；其他直播设置、对话模型不改变。
3. **AC-03**：给定当前配置 A，当输入无效配置或保存失败，则明确显示失败，生效配置与磁盘仍为 A；两位主人先后成功保存时，以最后一次成功保存为准。

#### 用户故事 2：先私有试听再决定保存（优先级：P1）

主人填写短句，试听未保存的音色。独立测试为草稿试听、对比线上配置、取消并检查舞台和会话无变化。

1. **AC-04**：给定生效配置 A、草稿 B，当点击试听，则当前控制台获得 B 的音频并可播放，刷新后仍为 A；舞台、直播记录、GLM 会话均没有试听事件，也不调用对话模型。
2. **AC-05**：给定试听正在生成或播放，当取消、修改草稿、切换后端、关闭 Drawer 或开始替换试听，则旧试听停止，晚到的旧响应不能覆盖或播放在新结果之上；主人仍可重试。
3. **AC-06**：给定空白试听文本，当打开声音区域，则有填写提示且不能发起试听；超过允许长度、服务失败、超时或缺少配置时显示可恢复错误，不自动换后端。

#### 用户故事 3：选择现有云端或本地声音（优先级：P1）

主人在同一声音区域切换三种现有后端。独立测试为逐一选择、检查适用配置、保存/试听，并验证其他后端已填值仍保留。

1. **AC-07**：给定任一后端，当切换 yovoice、macOS、豆包，则只展示所选后端的适用声音参数；保存后再切回时，其他后端已保存值仍在，不把豆包 speaker ID 描述成自由音色描述。
2. **AC-08**：给定豆包音色需要新版 API Key 或旧版 APP ID/Access Key，当选择该音色，则显示对应凭据要求，复用已有安全保存入口；缺少凭据时明确提示且试听失败，不隐式使用其他声音或服务。
3. **AC-09**：给定旧 settings 没有新声音配置，则首次使用沿用已有环境与豆包设置；豆包“跟随角色默认”在切换角色后仍随角色变化，旧 voice 更新入口仍可用。本地彩排和 `show_stats` 的本地费用语义不变。

#### 边界情况

试听排队时取消、保存与未消费预合成同时发生、播放中保存、跨浏览器保存、云端凭据缺失、Mac 音色未安装、yovoice 模型未安装或上一任务终态未知，均按上述场景检查。未知任务终态保持明确错误，不能通过新建并发任务“恢复”。实际参数边界由下列规则和工程 schema 定义。

#### 关键实体

- **生效声音配置**：最近一次成功保存的后端与各后端声音参数；不是密钥仓库。
- **声音草稿**：当前浏览器尚未保存的编辑值；可以用于一次试听。
- **一次合成快照**：一条声音开始合成时使用的配置；保存不追溯修改它。
- **试听结果**：有界短句生成的临时音频，仅供当前控制台播放，可取消和释放。
